## Как открыть проект в Godot

Папка `.godot` отсутствует, поскольку она исключена через `.gitignore`. Поэтому напрямую импортировать скачанный проект в Godot может не получиться.

Чтобы открыть проект:

1. Создайте новый проект в Godot.
2. Назовите корневую папку `образец-номер-9`.
3. Скопируйте в неё файлы из этого репозитория, согласившись на замену файлов с совпадающими именами.
4. Откройте созданный проект в Godot.
